# Free LLM API Collector

## Overview

This is a Python script that collects information about free large language model APIs from both international and domestic providers.

## Key Features

- **International Providers**: OpenAI, Anthropic, Google, Cohere, Hugging Face, Replicate, X.ai, OpenRouter, Opencode, Cline
- **Domestic Providers**: Baidu Wenxin, Tencent Hunyuan, Baidu BoostGB
- **Complete Information**: Registration requirements, quota limits, supported models
- **Export Options**: JSON and Markdown formats
- **Chinese Interface**: Full Chinese documentation and output

## Usage

1. Install Python if not already installed
2. Run the script: `python free_llm_collector.py`
3. Check the generated files:
   - `free_llm_providers.json` - structured data
   - `free_llm_providers.md` - human-readable format

## Files

- `free_llm_collector.py` - Main script
- `free_llm_providers.json` - Exported data (generated)
